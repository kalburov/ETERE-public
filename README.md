# ETERE · рекламни материали

Публичен архив **само с рекламни материали** на ETERE и партньорите ни: банери, видеа, снимки за реклами и рекламни текстове.

> ⚠️ Репото е **публично**. Тук не се качват клиентски данни, доставни цени, договори, пароли и други вътрешни документи. Те отиват в частното репо на ETERE.

## Как е подредено

Всяка кампания е в отделна папка с дата и име:

```
2026-11-black-friday/          ← Black Friday в аутлета, 16–29.11.2026
  etere/
    banneri/                   ← готови банери, 4x5 (лента) и 9x16 (Stories/Reels)
    video/                     ← готови Reel-ове с надписи, без звук
  santinelli/
    banneri/
    video/
  originali/                   ← изходни снимки и видеа (видеата са без звук, 1080p)
    etere/
    santinelli/
  tekstove.md                  ← рекламните текстове + ID-та на кампаниите в Meta
instrumenti/                   ← скриптовете, с които са правени банерите и Reel-овете
```

**Имена на файлове:** `<код>_<тема>_<формат>.jpg`, например `E2_zimni_yaketa_4x5.jpg`.
- `E…` = ETERE (дамско), `S…` / `0…` = SANTINELLI (мъжко)
- `4x5` = 1080×1350 (Facebook/Instagram лента), `9x16` = 1080×1920 (Stories, Reels)

## За нова кампания

1. Създай папка `ГГГГ-ММ-име/` (например `2026-12-koleda/`).
2. Качи суровите снимки и видеа в `originali/`.
3. Готовите банери и видеа отиват в `etere/` и `santinelli/`.
4. Текстовете и ID-тата от Ads Manager отиват в `tekstove.md`.

Файловете могат да се качват директно в рекламния акаунт ETERE по линк от това репо (`raw.githubusercontent.com/kalburov/etere-public/main/...`).
